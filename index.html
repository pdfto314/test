🎬 Cenas

Uma cena guarda os ambientes, os sons aleatórios e seus volumes. Toque numa cena para trocar com transição suave.
＋ Adicionar sons

Para enviar sons direto deste aparelho para o repositório, conecte ao GitHub uma vez (o token fica cifrado com uma senha sua).

Arraste arquivos ou pastas aqui mp3, m4a, wav, ogg · o nome do arquivo vira o nome do som · até 20 s vira efeito · pastas viram temas (Grupo/Tema)

    Como usar

    • Toque num ambiente para ligar/desligar o loop; num efeito para tocar uma vez.
    • Segure um som para ver opções: loop, 1×, 🎲 aleatório (toca sozinho de tempos em tempos), volume, favorito e editar.
    • 🎬 Cenas guardam o que está tocando; trocar de cena faz transição suave.
    • Em cada tema, 🎲 Surpresa toca um efeito aleatório do tema.
    • Teclado: / busca · Esc limpa a busca.
