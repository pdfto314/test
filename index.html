＋ Adicionar sons

Os sons vão direto para o repositório no GitHub e aparecem aqui em ~1 minuto. Para isso, conecte uma vez com um token:

  1. Abra criar token no GitHub.
  2. Em Repository access, escolha Only select repositories → este repositório.
  3. Em Permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole abaixo.

O token fica salvo só neste aparelho.
