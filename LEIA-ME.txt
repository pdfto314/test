JOGATINA SOUNDBOARD
===================

Usar no iPad
- Abra o link do site no Safari e toque em Compartilhar → "Adicionar à Tela de Início".
  Ele abre em tela cheia, como um app.
- Toque em "Começar" (o iPad só libera áudio depois de um toque).
- Toque num som = toca em loop (ambiente). Toque de novo = para (com fade).
- Botão 1× = toca uma vez (efeito).
- Embaixo, em "Tocando", ajuste o volume de cada som ou pare com ✕.
  Os controles "Ambiente" e "Efeitos" são o volume geral de cada tipo.
- 🎬 Cenas: salve o que está tocando (ex.: "Taverna chuvosa") e troque de
  cena com transição suave.
- 🔎 Busca procura em todos os temas.
- A tela fica acesa enquanto tiver som tocando.

Adicionar sons pelo iPad (ou pelo navegador do PC)
1) Toque em "＋ Sons".
2) Na primeira vez, conecte com um token do GitHub (as instruções aparecem na tela):
   github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
   - Repository access: Only select repositories → este repositório
   - Permissions → Contents: Read and write
   O token fica salvo só naquele aparelho.
3) Escolha o tema (ou crie um novo), selecione os arquivos e toque em Enviar.
   Os sons aparecem em ~1 minuto (tempo do GitHub Pages publicar).

Adicionar sons pelo PC (git)
- Coloque os arquivos em audio/<Tema>/ (cada pasta é um tema) e faça Commit + Push na main.
- O GitHub Action (.github/workflows/playlist.yml) atualiza o playlist.json sozinho.
  Depois disso, rode "git pull" antes do próximo commit.
- Se o Action falhar ao dar push: Settings → Actions → General → Workflow permissions
  → "Read and write permissions".
- Manual (opcional): generate_playlist.bat no Windows, ou "python gerar_playlist.py".

Formatos aceitos: mp3, m4a, wav, ogg, mpeg.
